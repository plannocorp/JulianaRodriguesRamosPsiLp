# Este projeto

Site estático em HTML, CSS e JavaScript. Não há dependências, framework ou build. Preserve os caminhos relativos dos assets e o idioma pt-BR.

- Execute `python3 scripts/check_site.py` e `node --check script.js` para validar alterações relacionadas.
- Confira o layout móvel e o menu ao alterar a interface.
- Fontes públicas verificadas estão em `docs/RESEARCH.md`. Não invente CRP, formação, preços, depoimentos ou resultados clínicos. Não substitua a foto por uma pessoa diferente.
- Siga as preferências globais do usuário: homolog → PR para deploy; commit/push e merge conforme autorização específica da tarefa.
